01What it is

Horizon rebuilds Minecraft: Java Edition 26.3 in Rust, one subsystem at a time, and holds every piece to the same inputs as the vanilla game until the outputs are identical.

01

Your own copy

Install Java Edition with the official launcher and play 26.3 once. Horizon builds its resources from those files on your machine, and never downloads or shares game files.

02

Native on three platforms

Linux, macOS on Apple Silicon and Windows. Worlds come from a Rust port of the vanilla generators, drawn with vanilla's block models, lighting, sky and fog.

03

Open source

Horizon's code is MIT. It contains no Minecraft code, assets or data; those belong to Mojang and Microsoft under the Minecraft EULA.

02In game

Drawn by Horizon

Captured in the Rust client itself, with vanilla assets from the player's own copy and no mods or shaders.

04The launcher

One small app, then play

The launcher installs Horizon, prepares it from your copy of the game and keeps both up to date.

  • 01

    One-click install

    Pick a release and it installs the build for your platform into its own folder, then prepares the resources from your Java Edition 26.3 install.

  • 02

    Updates on its own

    It looks for a new Horizon release when it starts and every four hours, and updates itself from the launcher's own releases.

  • 03

    Client or server

    Start the client, or host a server from the Servers page: create it, start it, watch players and the console, change its settings and keep backups.

  • 04

    Logs and crash reports

    The Settings page shows where the game's logs and crash reports are, and horizon-launcher logs prints them.

  • 05

    Modpacks and packs

    The Modpacks page reads a Modrinth or CurseForge pack and carries over the mods Horizon can run. The Mods page installs resource packs, shader packs and modpacks from Modrinth.
