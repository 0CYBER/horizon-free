Horizon: Minecraft Java Edition 26.3, rewritten in Rust
=========================================================

Horizon is an unofficial fan project, not affiliated with, endorsed by or
connected to Mojang Studios or Microsoft. Minecraft is a trademark of Mojang
and Microsoft. This package contains none of Minecraft's code, textures or
sounds: you need your own copy of Minecraft Java Edition, and Horizon uses the
files from it.

What you need
  - Minecraft Java Edition, bought and installed with the official launcher,
    with version 26.3 downloaded at least once (play it once from the launcher).
  - Python 3.12 or newer.
  - Java 25 (a JDK, e.g. Eclipse Temurin 25).
  - A graphics driver with Vulkan (Linux, Windows) or any Apple Silicon Mac.

First start (once, a few minutes)
  1. Open a terminal in this folder.
  2. Run:   python3 tools/prepare_native_client.py --prepare
     (on Windows: py tools\prepare_native_client.py --prepare)
     It reads the game files from your own Minecraft installation and writes
     the resources Horizon needs into .local/ in this folder. If your launcher
     keeps the game elsewhere, add --minecraft-dir PATH.

Play
  Linux:    ./horizon-client
  macOS:    ./horizon-client   (first time: right-click > Open, or
            xattr -d com.apple.quarantine horizon-client)
  Windows:  horizon-client.exe
  Run it from this folder. horizon-client --help lists the options
  (render distance, world, seed, joining a server...).

Controls: mouse look, WASD move, Space jump, Left Shift sneak, Left Ctrl
sprint, left click break, right click place/use, 1-9 or scroll for the hotbar,
E inventory, Q drop, F1 hide the HUD, F3 debug, Esc pause.
